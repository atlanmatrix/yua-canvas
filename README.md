# Canvas of Yua

默认将工作区保存在浏览器本地的无限画布，支持文本、任务、图片、Markdown、PDF、Mermaid、嵌套画布与本地应用关联。无需账号即可使用；可选云同步、登录和只读分享的部署说明见 [worker/README.md](worker/README.md)。

## 开发与验证

需要 Node.js 22.12+，当前验证环境为 Node.js 24。

```sh
npm ci
npx playwright install chromium
npm run dev
```

```sh
npm run build          # TypeScript 检查和生产构建，输出 dist/
npm test               # 浏览器交互及性能回归
npm run check:worker   # 可选云服务类型检查
npm run test:cloud     # 本地 workerd、D1、R2 集成测试
npm run test:pwa       # Pages 子路径、生产资源和离线验证
```

开发服务器监听所有网卡，仅用于开发。`npm run preview` 用于预览生产构建；开发环境不注册 Service Worker。

## 画布操作

- 双击空白处创建文本；画布右键「新建」可创建文本、任务、图片、文件、Mermaid、Miniature 或分组，位置按右击点计算。新建文件直接生成可编辑的文件组件；已有文件可上传、拖入或粘贴。
- 除分组和子画布外，组件右键提供小、中、大三档显示模式，默认新建为中尺寸。小尺寸显示类型图标，中尺寸缩小预览，大尺寸按组件保存的尺寸展示。切换模式保留原始内容与布局数据。
- 所有组件和分组支持遮罩、右侧备注及背景色。遮罩会卸载实际内容。分组支持平铺或列表：列表左侧选择组件，右侧显示内容，切回平铺保留原坐标。
- 文本双击后在画布内编辑，浮动工具栏支持字体、字号、加粗、倾斜、下划线、删除线、文字颜色和背景色。Cmd/Ctrl + Enter 完成，Esc 取消整次修改。
- TODO 双击事项会从点击位置继续编辑，双击标题或空白处新增事项；Enter 在当前项后新增。原有事项 ID、完成状态与连线保留，整次编辑可撤销。
- 粘贴图片按原始像素尺寸展示；宽度超过 2560 或高度超过 1440 时，默认按 50% 展示。原始文件字节保留。普通文件上传仍使用适合画布的初始预览容器。
- 画笔入口位于底部工具栏左侧，间隔 12px。点击或按 P 进入绘画模式，顶部工具栏提供颜色、粗细、撤销、清空、隐藏和退出；Esc 退出。笔迹自动平滑，位于组件内容上方，隐藏状态和笔迹随画布保存。
- 普通拖动移动组件，空白处拖动框选。Shift 或 Cmd/Ctrl + 点击增减多选；右键拖动、空格拖动或 Cmd/Ctrl + 拖动平移。滚轮平移，Cmd/Ctrl + 滚轮缩放。
- 悬浮组件后，可从边缘的「+」拖出带箭头的曲线连线；TODO 每项有独立连接点。双击曲线或标签编辑连线文字，Enter / 失焦保存，Esc 取消。删除组件或事项会清理相关连线。
- 分组标题可拖动全部后代成员，双击重命名。成员部分越界时分组扩张，完全离开时保留原边框；分组可独立调整尺寸、解散或删除。
- 左下角缩略图显示组件、分组、连线和笔迹，蓝框表示视口，可拖动定位。灰色画布边框对应缩略图完整范围。不提供侧栏、搜索或筛选。
- 组件或分组可设置 Pin；点击后以非线性平移及先缩小后放大的动画定位，额外缩小最多 10%。目标超出视口时用 1600ms，视口内按距离用 400–1000ms。拖动、滚轮、Esc 或再次定位可以打断动画。

## 文档、图表与应用关联

- Markdown 文件直接渲染标题、列表、表格、代码块及任务列表。双击打开详情，可编辑完整内容、文件名，预览未保存的修改；保存保留编码、BOM 和换行惯例。原始 HTML 不执行。
- PDF 直接预览，默认首页；悬浮显示上下页图标。当前页码随本地保存、同步和备份保留。字体、CMap、解码器与 Worker 随应用构建，支持离线和部署子路径。
- 粘贴 Mermaid 代码或单个 Mermaid 围栏块会生成独立图表，也可从右键菜单创建。画布只显示完整图表，双击弹窗编辑。Markdown 中同时支持 Mermaid 和传统 flowchart.js 围栏语法；解析失败时保留可编辑源码。
- 画布右键「新建应用关联」可添加 VS Code 或 iTerm2。VS Code 胶囊带图标，使用官方协议的 `windowId=_blank` 参数在新窗口打开配置的完整本地路径。
- iTerm2 组件支持多行命令，每行前显示 `>` 图标，悬浮时可复制或执行，双击配置。首次执行按弹窗安装 macOS 本地打开器，之后每次在 iTerm2 新窗口输入命令。配对密钥仅保存在当前浏览器及用户安装的打开器中，不进入工作区备份或云同步。只读分享不会执行应用关联；macOS 应用启动及自动化权限仍需实机验证。
- 底部工具栏可创建子画布，顶部返回父画布；根画布还可从右键创建一次父画布。每层的内容、平移、缩放和上次所在层级分别保存。
- 缩略图右键「3D 预览」打开 `#/3d` 分层视图。支持拖动旋转、滚轮缩放、Shift / 右键平移和触屏手势；双击组件返回其画布并打开。3D 预览不改变组件布局。
- Miniature 可配置 HTTP / HTTPS 场景 URL 或 iframe 代码，只提取地址与标题。双击激活交互，点击外部保存视角和静态封面并释放 iframe。自动封面依赖场景实现 `little-worlds:ready/statechange/capture/response` 协议；仅允许来源窗口、源站和请求标识匹配的响应。未实现截图协议的场景仍可手动交互。

## 大画布预览性能

卡片的布局、连接点和选择范围始终保留；附件和图表内容由共享可见性观察器按需激活，在视口周围预留 320px。离开范围后延迟释放，正在聚焦或选择文字的内容保持活跃。平移、缩放过程中暂停启动新的重预览，停下约 160ms 后补充内容。缩得很小的文档先显示轻量类型图标，悬浮或放大后恢复预览，保存的显示模式不变。

卡片通过独立的 memo 组件与稳定事件桥隔离相机更新；缩略图卡片和投影也避免无关计算。位置、显示模式、编辑和选中状态改变时仍正常更新对应组件。

- PDF 解码及页面渲染最多 2 个并发任务，取消离屏队列任务，复用短期文档实例。文档池限制数量及附件字节，并在空闲约 10 秒后释放；正在使用的文档不会被淘汰。
- 页面预览按文件内容、页码和清晰度分档缓存，预览最长边限制为 1024 像素。内存 LRU 按估算像素成本限制为 64MB；独立的 IndexedDB 派生缓存最多 128 项、64MB，刷新后可复用。缓存不可用或写入失败时仍可正常预览和保存原文件。
- 文本解码结果和 Markdown 解析树分别有容量上限；超过 64 个顶层块的 Markdown 按块组虚拟化显示，滚动到相应位置再挂载内容，保持完整文件及文内引用。
- Mermaid / flowchart.js 串行渲染并复用已清理的 SVG，实例使用独立 ID，避免重复图表的箭头、裁剪和样式相互干扰。

这些缓存都可重新生成，不属于工作区数据，不进入导出或云同步；淘汰缓存不会删除原始附件。性能回归覆盖离屏加载数量、相机移动时的卡片更新、渲染并发、缓存失效、翻页恢复及长文档滚动，具体帧率仍取决于设备和文档复杂度。

## 保存、备份与云服务

本地数据位于当前浏览器、当前网站来源的 IndexedDB。最后一次操作后约 0.6 秒自动保存，视口变化不计入内容撤销历史。更换网站来源或浏览器不会自动迁移数据，请定期导出。

顶部「导出画布」始终导出整个工作区，包括父级、兄弟、子画布、原始附件、分组、任务、连线、Pin、样式、备注、笔迹、隐藏状态与各层视图。导出使用当前内存状态，无需等待自动保存。完整备份导入会确认替换范围，事务写入成功后应用，并可撤销；旧版单层画布 JSON 仍可导入当前层。

右键「下载」选中组件或分组会生成局部 ZIP，保留原始字节和布局元数据。上传、拖入或粘贴带元数据的 ZIP 会以独立 ID 合并；普通 ZIP 展开为附件。损坏或缺少引用文件时不会部分导入。剪切缓存可跨刷新恢复，但系统剪贴板必须保留对应标识。

可选云服务按账号同步完整工作区，支持固定快照分享、有效期和撤销，配置见 [worker/README.md](worker/README.md)。分享令牌允许持有者读取和下载；撤销不能收回已下载的数据。浏览器存储回收、清理网站数据或卸载应用可能丢失本地工作区，派生预览缓存不能代替备份。

## 部署、安装与离线

推送 `main` 后，[GitHub Pages 工作流](.github/workflows/deploy-pages.yml) 自动构建部署；仓库 Pages 来源应设置为 GitHub Actions。项目默认地址为 <https://atlanmatrix.github.io/yua-canvas/>，实际结果以 Actions 为准。

```sh
npm run build -- --base /yua-canvas/
npm run preview -- --base /yua-canvas/ --port 4173 --strictPort
```

`dist/` 也可部署到其他静态托管服务。云服务使用同域 Worker 站点；GitHub Pages 入口使用本地模式。

生产版支持 PWA 安装。首次联网加载后，应用外壳和构建资源可离线使用；API、会话和云端附件不进入 Service Worker 缓存。登录、同步和打开尚未加载的分享仍需网络。

发现更新时显示「更新应用」，点击后先保存工作区再重新加载，其他标签页不强制刷新。Manifest、Service Worker 和 PDF 资源跟随部署子路径。图标源文件为 `public/icon.svg`，修改后可执行 `npm run icons` 重新生成安装图标。
