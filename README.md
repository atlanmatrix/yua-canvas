# Canvas of Yua

一个默认将数据保存在浏览器本地的无限灵感画布。本地模式无需账号；可选 Cloudflare 云服务支持 GitHub 登录、多设备同步和只读快照分享。

云服务的配置、部署、验证与当前边界见 [worker/README.md](worker/README.md)。

## 开发

需要 Node.js 22.12+（当前环境验证版本为 Node.js 24.19.0）。

```sh
npm ci
npm run dev
```

```sh
npm run build       # TypeScript 检查和生产构建，输出到 dist/
npm run preview     # 本地预览生产构建
npx playwright install chromium
npm test            # 浏览器端功能测试
```

`dist/` 可以部署到任意静态网站托管服务。开发服务默认监听所有网卡，仅用于开发。

## GitHub Pages 自动部署

仓库已配置 `.github/workflows/deploy-pages.yml`：推送到 `main` 时自动构建并部署，也可以在 Actions 中手动运行 **Deploy to GitHub Pages**。

首次使用需在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，并确保仓库允许 Actions 运行。若仓库或组织策略要求审批部署，请按 GitHub 提示处理。

工作流使用 Node.js 24 和 `npm ci`，根据 Pages 配置自动设置 Vite 的部署子路径，上传 `dist/` 并部署。默认项目地址为 <https://atlanmatrix.github.io/yua-canvas/>；实际地址以成功部署后的 Actions 输出为准。GitHub Pages 的可用性受仓库可见性、账号方案及组织策略影响。

本地验证相同的子路径构建：

```sh
npm run build -- --base /yua-canvas/
npm run preview -- --base /yua-canvas/ --port 4173 --strictPort
```

浏览器本地开发地址与 Pages 地址的数据互不共享；需要使用导出/导入迁移画布。

## 使用

- 左下角画布缩略图右键「3D 预览」打开独立的 `#/3d` 页面，按父子画布分层展示整个工作区，同层画布并排显示，保留组件位置、分组及连线。拖动旋转，滚轮或底部按钮缩放，Shift / 右键拖动平移；触屏支持单指旋转和双指缩放、平移。右侧画布列表可聚焦、进入指定画布、仅显示聚焦画布或调节层间距。双击组件（键盘 Enter 同样支持）会返回其所属画布、定位组件并立即执行原有双击操作；文本和任务进入编辑、附件打开预览、miniature 打开场景编辑、子画布继续进入下一层。Esc /「返回画布」退出；支持浏览器前进后退、刷新恢复和离线访问。3D 视角操作不改变原画布布局，预览使用静态内容，不挂载场景 iframe。
- 新增 `miniature` 类型：底部工具栏或画布空白处右键「新建 → Miniature」，粘贴 HTTP / HTTPS 场景 URL 或完整 iframe 代码，支持一键填入「被自然收回的城市街角」示例（<https://atlanmatrix.github.io/codex-playground/city/>）。场景以无边框、宽度 100%、默认高度 480 的懒加载 iframe 展示，支持全屏；点击「交互」操作 3D 场景，「结束交互」恢复卡片拖动，双击或点击编辑图标修改名称和地址。支持调整尺寸、连线、分组、复制、撤销、本地保存、云同步、只读分享及 JSON / ZIP 导入导出。仅提取 iframe 的地址与标题，不执行粘贴代码中的其他属性或 HTML；外部站点须允许被 iframe 嵌入。
- 支持多层嵌套画布。底部「创建子画布」或画布空白处右键「创建子画布」生成入口节点，点击节点内图标（或双击节点）进入；顶部返回按钮回到父画布。子画布节点支持右键重命名、复制、改色和删除，可与其他节点连线和分组。
- 根画布空白处右键「创建父画布」会把当前内容完整包为子画布；每个子画布只有一个直接父画布，已有父级或已执行过该操作时禁用继续创建父画布。每层的平移、缩放和上次所在层级均自动保存，撤销结构变化后会返回有效的层级。
- 顶部「导出画布」或 Cmd/Ctrl + Shift + E 始终导出整个工作区，即使正在子画布中，也包含根画布、父级、兄弟及所有子画布和全部组件、原始附件、分组及嵌套关系、任务状态、连线及文字、Pin、颜色、尺寸和文本显示设置。备份还记录每层缩放和平移、当前所在层级；导入新格式备份会替换整个工作区，保留原有 ID 并恢复视图，附件在 JSON 中完整内嵌，无需依赖旧浏览器或云端。还原前展示完整工作区的替换范围，损坏或写入失败时保留原数据。旧版画布 JSON 仍导入当前层；单个子画布下载和选中元素的 ZIP 是局部迁移，复制、重复与 ZIP 合并会生成独立 ID。ZIP 中子画布附件放入各自目录，元数据只记录布局与层级。Miniature 备份其地址及组件配置，不打包外部网站内容；登录状态、会话撤销记录和剪贴板缓存不属于工作区备份。
- 文本文件双击后保留预览，可切换「编辑」修改完整内容（不受预览 1 MB 限制），点击「保存文件」或 Cmd/Ctrl + Enter 保存，支持空文件；预览切换显示未保存的 Markdown 编辑。关闭弹窗或 Esc 放弃尚未保存的修改。文件名、后缀、UTF-8 / UTF-16 LE / UTF-16 BE 编码、BOM 和换行惯例保留；保存后缩略图、下载和导出同步更新，可撤销。

- 粘贴单个 HTTP / HTTPS 链接或 `www.` 地址默认显示为普通文本，按住 Cmd/Ctrl 时才显示蓝色下划线和可点击光标。Cmd/Ctrl + 点击在新标签页打开；普通点击选择，双击编辑，Cmd/Ctrl + 拖动仍平移画布。原始文本、复制及下载内容保持不变。

- 粘贴或拖入目录会按目录名生成分组，递归创建子分组，并将文件、文本文件和图片按原始名称作为元素排入对应分组；支持目录条目分批读取，保留可枚举的空目录，整个导入可一次撤销。浏览器未提供目录剪贴板内容时，可使用工具栏「导入目录」；目录选择器仅能读取浏览器提供的文件和相对路径。目录里的 ZIP 文件作为原始附件保留。
- 自动保存也会记录缩放比例和画布平移位置，刷新或在同一浏览器打开新标签页后恢复；首次使用及无效视图记录会使用默认视图。视图单独存储在本地，不改变元素坐标，不计入撤销历史。
- 曲线连线在目标端显示箭头，拖动预览和缩略图也显示方向；主画布箭头在缩放时保持清晰可见。

- Markdown 预览支持 `mermaid`、`flowchart` / `flow` / `flowchart.js` 围栏代码块，可渲染 Mermaid 流程图、时序图等，以及传统 flowchart.js 的 `st=>start` / `st->op->e` 语法。图表在本地按需加载和渲染，解析失败时保留源码。
- 分组右键、选中卡片右键或保留选择后在画布空白处右键「下载」，会打包 ZIP。多选和框选包含全部选中元素，分组包含全部后代元素及子画布。文件、图片保留原始名称及字节，重名文件仅在包内增加编号；文本保存为时间命名的 `.txt`，Todo 保存为 `.todo.json`。额外的 `yua-canvas.metadata.json` 保存元素类型、位置、尺寸、分组、连接点、连线文字和文件映射，正文与附件不重复写入元数据。
- 上传、拖入或粘贴 ZIP 会自动解压；导入按钮也支持 ZIP。普通压缩包的文件分别展示为元素；带画布元数据的 ZIP 恢复原布局、分组、Todo 和内部连线，并以独立 ID 合并到当前画布，可一次撤销。原始 ZIP 中的文件夹结构不会变成分组；目录内文件显示原文件名。损坏或缺失引用文件的包不会部分导入。
- 连线文字位于独立图层，始终显示在所有曲线及拖动预览之上。双击连线或已有连线文字可直接输入文字，Enter / 失焦保存，Esc 取消；清空文字可移除标签。连线文字随画布保存、复制和导出。连线拖动到目标连接点附近（24 屏幕像素内）时，最近的可见 `+` 激活为蓝色并吸附；Todo 的每一条任务分别支持。

- 不提供侧栏、搜索或筛选。左下角缩略图始终自适应显示全部卡片、分组和连线，蓝色框表示当前视口；按住鼠标左键或触屏拖动缩略图可实时定位，松开、Esc 或失焦后停止。画布中的浅灰边框对应缩略图的完整范围（含留白），随元素布局自动更新，缩放时保持 1 像素线宽，不阻挡画布操作。

- 文本文件显示内容缩略图，下方为文件图标与完整文件名。悬浮卡片右上角可下载；文件、图片保留原始名称、后缀和字节，纯文本导出为浏览器本地时间命名的 `YYYY-MM-DD_HH-mm-ss-SSS.txt`。
- 文件、图片和 Todo 右键菜单支持下载；文本右键菜单支持复制、下载、打开，普通文本进入画布内编辑，链接在新标签页打开。
- 所有卡片和分组标题的右键菜单均提供横向七个浅色圆点，可设置白、粉、橙、黄、绿、蓝、紫背景；多选卡片可一起改色，分组改色只影响分组框。颜色支持自动保存、撤销、复制及 JSON / ZIP 导入导出，缩略图同步显示。
- 按下右键立即显示抓取手型，拖动平移画布；按住右键时滚轮以指针为中心缩放，可继续平移，松开后恢复普通滚轮操作。原地右击卡片或分组标题仍打开对应菜单。
- 卡片、分组标题悬浮显示可抓取小手，按下拖动时保持抓取光标；松开、取消或窗口失焦后恢复。缩放边框和连线使用各自的操作光标。

- 直接粘贴纯文本会生成无标题栏文本块，默认每行最多 80 个等宽字符，可用右上角图标切换自动换行与保留原始行的横向滚动模式。高度随内容变化，最多直接显示 20 行；短文本不显示纵向滚动条，超过 20 行在块内滚动，选中后的左右边框可调整宽度并自动重算高度。模式随保存、复制和 JSON / ZIP 导入导出保留。图片按原始比例显示为无标题栏预览框，调整边框时保持比例。尺寸会随画布保存和导出。
- 元素可以自由堆叠；新建、导入、粘贴、复制、拖动和调整尺寸都不检查碰撞，也不挤开其他元素。分组自动包含、边框扩张和嵌套关系仍保留。

- 底部工具栏包含 Todo、图片、文件、目录和子画布；Todo、图片、文件和子画布按钮可直接拖到画布定位，图片和文件松手后选择上传内容。文本可用粘贴、双击画布空白处或 N 快捷键创建。拖到画布外或按 Esc 取消。
- 卡片拖动结束后，只要仍与原分组相交，就扩张边框完整容纳；完全移出原分组才离组。新接触的分组也会按需扩张容纳。空分组框保留。
- 点击分组标题栏不选中组内元素，拖动标题栏会移动所有层级的子分组及其卡片。子分组拖动、缩放后，部分相交时扩张父分组，完全移出才离开父分组；重叠时选择最小父框，同尺寸分组不会互相嵌套。
- 分组标题栏右侧「自适应」按钮按当前所有成员（包括隐藏卡片、子分组边框）收紧或扩大边框，不移动内容。没有成员时保持原尺寸。

- 添加仅含内容的文本、批量上传图片和任意文件，或直接拖入文件。
- 在画布中按 Cmd/Ctrl + V 粘贴剪贴板中的图片（包括截图）和文件，支持批量粘贴。可粘贴的文件类型取决于操作系统和浏览器是否向网页提供文件数据；输入框和编辑弹窗中保留原生粘贴行为。
- 拖动卡片定位；空白处拖动框选；Shift 或 Cmd/Ctrl + 点击增减多选；Cmd/Ctrl + 拖动仍平移画布，Cmd/Ctrl + 点击链接文字仍在新标签页打开。
- 按住鼠标右键、空格或 Ctrl/⌘ + 鼠标左键拖动画布，或使用移动工具；滚轮平移，Ctrl/⌘ + 滚轮缩放。
- 双击文本在画布内直接编辑，无需标题或弹窗；输入时继续自动保存，点击其他位置或按 Cmd/Ctrl + Enter 结束编辑，Esc 取消本次修改。新建文本也直接在画布内输入；双击附件查看原图、Markdown、PDF、音视频，其他文件提供原文件下载。
- Todo 卡片可创建多项任务、勾选完成；双击后直接在画布内添加、修改或删除任务，Enter 新增下一项，点击外部或 Cmd/Ctrl + Enter 结束，Esc 取消本次修改。工具栏及 T 快捷键新建任务也在画布内编辑。底部状态栏已移除；任务状态随输入自动保存，并支持撤销和导入导出。
- 分组框平时保持固定；成员部分越界时扩张，完全离开时保留原边框。拖动边或四角可调整尺寸，最小尺寸为 160 × 120 画布单位。
- 多选后创建并命名分组；按住画布中的分组标题栏可拖动整个分组及所有后代成员，双击标题栏在画布内原地重命名。分组可在画布内重命名，右键解散或下载。
- 有未保存改动时，最后一次操作后等待 0.6 秒自动保存到 IndexedDB，期间继续操作会重新计时；仅更新状态指示，不弹出保存通知。导出使用当前内存中的最新工作区内容，无需等待自动保存；完整备份还原会在本地数据及视图的同一个事务写入成功后应用，仍可撤销这次内容替换。导入前需要确认完整工作区或旧版单层画布的替换范围。

## 数据说明

未连接云端时，数据仅存于当前浏览器、当前网站来源下，不自动同步或上传。登录后点击右上角「云同步与分享」连接云端，会上传整个工作区和附件；可以暂停同步或退出。分享链接允许任何持有者查看和下载快照，可设置有效期和撤销。清理网站数据、更换设备、隐私模式或浏览器存储回收均可能丢失数据，请定期导出备份。附件与导出受设备内存和浏览器存储配额限制；保存失败时界面会提示。任意上传文件均作为附件处理，不执行 HTML 或脚本。请仅导入信任的备份文件；PDF 等原生预览取决于浏览器支持。

右下角「?」可查看使用说明、完整快捷键及构建版本。版本格式为 `YYMMDD.<hash>`，日期取北京时间的构建日期，hash 为当前 Git 提交的前 7 位，构建时写入，离线可查看。任意卡片或分组右键选择「Pin」后，导入导出下方显示纵向定位列表；点击跨画布定位，双击直接重命名，再次右键可取消 Pin。Pin 随保存、同步及 JSON / ZIP 导入导出保留。缩略图闲置 1.2 秒后淡出，悬浮、缩放和拖动时恢复；右侧短线显示画布层级，深灰表示当前画布，悬浮预览、点击切换，预览不会修改导航位置。

技术栈：React、TypeScript、Vite、Lucide；端到端测试使用 Playwright。

## 画布编辑

点击分组标题选中分组，不会选中内部卡片。Cmd/Ctrl + C 复制，Cmd/Ctrl + V 在当前画布中生成偏移的新副本；分组包含所有层级的子分组、卡片、任务状态和原始附件。副本使用独立 ID，保留内部层级。画布内部复制缓冲保留到刷新前，复制其他应用的内容后不会误粘贴旧副本。

Cmd/Ctrl + Z 撤销；Cmd/Ctrl + Shift + Z 或 Ctrl + Y 重做。拖动、调整边框的一整个手势为一次历史记录，编辑、创建、删除、导入和解散分组也可撤销。历史仅保留本次页面会话的最近 100 步；编辑框内保留浏览器原生撤销。

选中节点后不显示浮动选择工具栏；非分组卡片右键可将当前选择创建为分组（支持单个卡片），或将选中卡片移出分组；分组标题右键可解散分组并保留内容。右键菜单按内容操作、分组、外观、删除分区，以分隔线区分；删除节点会同时清理相关连线，多选时删除整个选择，删除分组会移除本身及全部后代内容，可一次撤销。双击分组标题原地改名，Enter 或失焦保存，Esc 取消。

## 系统剪贴板复制

选中卡片后按 Cmd/Ctrl + C，成功后显示「已复制」。文本可多选合并为纯文本；Todo 复制为任务清单；文本附件复制文件正文。图片复制为 PNG，可粘贴到支持图片的本地应用或编辑器。非 PNG 图片会转换为 PNG，动图仅复制静态画面；图片需逐张复制。

网页无法把任意附件写入 Finder/资源管理器的系统文件剪贴板。二进制附件可复制为画布内副本，向系统剪贴板仅写入文件名；同时提供「下载原文件」按钮；下载保留文件名和原始字节。不把文件链接或 Base64 当作原文件复制。文本附件在编辑器中粘贴为正文，不能在文件管理器里粘贴成原文件。复制文本附件后同样提供「下载原文件」，保留原文件名、编码、换行与全部原始字节；支持 UTF-8 和带 BOM 的 UTF-16 正文复制，无法可靠解码时提供原文件下载。

剪贴板功能需要 HTTPS（或 localhost）及浏览器授权；权限被拒绝会提示失败。编辑框内使用原生复制，不会复制画布选中卡片。

## 快捷键

输入框内保留系统快捷键；弹窗中可用 Esc 关闭，文本在画布内用 Cmd/Ctrl + Enter 结束编辑，分组表单可用 Cmd/Ctrl + Enter 保存。

| 快捷键                     | 操作                                   |
| -------------------------- | -------------------------------------- |
| V / H                      | 选择 / 平移工具                        |
| 空格 / Ctrl / ⌘ + 左键拖动 | 临时平移                               |
| N / I / U                  | 新建文本 / 上传图片 / 上传文件         |

## 连线

普通元素悬浮后在边框显示「+」，从连接点拖到另一个元素的连接点（或边框）即可生成贝塞尔曲线。Todo 每一条任务在左右边框都有独立连接点，随文本换行与列表滚动定位；分组本身不提供连接点。

连线随元素移动、调整尺寸与画布平移缩放更新，保存于浏览器并支持导入导出。点击曲线后按 Delete 删除；创建、删除可撤销/重做。删除元素或任务会清理对应连线。复制多个元素或整个分组时，仅复制内部连接，并生成新的元素、任务和连线 ID。

文件名称与图标在 100% 缩放下统一为 16px；`.env`、`*.env`、`.env.local` 等环境配置文件支持文本缩略图和全文预览。选中角块隐藏，边框和角部仍保留缩放热区。分组标题与自适应按钮共享同一标题栏背景。

剪切缓存会写入本地存储，刷新后仍可粘贴（系统剪贴板须保留对应内容）。剪切支持 `Cmd/Ctrl + X` 及卡片、分组右键菜单，保留子画布、附件、任务和内部连线；失败时不删除原内容。画布空白处右键可在该位置粘贴剪贴板内容，或返回父画布（根层不可用）。右键粘贴需要浏览器剪贴板读取权限；输入框和文本编辑器继续使用原生剪切、粘贴。

除分组和子画布外，文本、图片、文件和任务采用相同边框及阴影；连线默认使用更浅灰色，悬浮和选中时仍为蓝色。

画布空白处右键「新建」可展开二级菜单，创建文本、任务、图片、文件、子画布或分组，位置采用原始右击点（含缩放和平移换算）。图片与文件沿用原生文件选择器，取消选择不会创建元素。子菜单可悬浮或点击展开，也支持方向键、Enter 和 Esc；靠近窗口边缘时自动调整位置。


## PWA 安装与离线使用

生产构建支持 PWA，可在支持的浏览器中安装为独立应用。Chrome / Edge 出现安装入口时可点击右上角安装按钮；iPhone / iPad 使用 Safari 的「分享 → 添加到主屏幕」。需要 HTTPS 或 localhost。

首次联网打开后，Service Worker 缓存应用外壳和构建资源，之后可离线打开、编辑本地画布及本地附件。云同步、登录和打开尚未加载的分享仍需网络；API、会话和云端附件不进入 Service Worker 缓存。

发现新版本时显示「更新应用」，点击后先保存当前工作区和视图，再重新加载。其他已打开标签页不会强制刷新。为兼容其尚未加载的模块，仍有页面打开时保留旧静态缓存；无页面使用时激活新版本会清理旧缓存。卸载应用或清理浏览器站点数据可能删除本地画布，仍建议定期导出。

SVG 图标源文件为 `public/icon.svg`；PNG 安装图标和 Apple Touch 图标由该 SVG 渲染。Manifest 和 Service Worker 的作用域跟随部署路径，支持根路径与 `/yua-canvas/`。开发服务器不注册 Service Worker，离线功能需使用生产构建验证。

修改 SVG 后可运行 `npm run icons` 重新生成安装图标（需要 Playwright Chromium）；运行 `npm run test:pwa` 可验证生产子路径的安装配置、离线编辑和安全升级。
