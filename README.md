# Yua Canvas

一个纯前端、数据保存在浏览器本地的无限灵感画布。无需账号、服务器或 API 密钥。

## 开发

需要 Node.js 22.12+（当前环境验证版本为 Node.js 24.19.0）。

```sh
npm ci
npm run dev
```

```sh
npm run build       # TypeScript 检查和生产构建，输出到 dist/
npm run preview     # 本地预览生产构建
npx playwright install chromium
npm test            # 浏览器端功能测试
```

`dist/` 可以部署到任意静态网站托管服务。开发服务默认监听所有网卡，仅用于开发。

## GitHub Pages 自动部署

仓库已配置 `.github/workflows/deploy-pages.yml`：推送到 `main` 时自动构建并部署，也可以在 Actions 中手动运行 **Deploy to GitHub Pages**。

首次使用需在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，并确保仓库允许 Actions 运行。若仓库或组织策略要求审批部署，请按 GitHub 提示处理。

工作流使用 Node.js 24 和 `npm ci`，根据 Pages 配置自动设置 Vite 的部署子路径，上传 `dist/` 并部署。默认项目地址为 <https://atlanmatrix.github.io/yua-canvas/>；实际地址以成功部署后的 Actions 输出为准。GitHub Pages 的可用性受仓库可见性、账号方案及组织策略影响。

本地验证相同的子路径构建：

```sh
npm run build -- --base /yua-canvas/
npm run preview -- --base /yua-canvas/ --port 4173 --strictPort
```

浏览器本地开发地址与 Pages 地址的数据互不共享；需要使用导出/导入迁移画布。

## 使用

- 工具栏中的笔记、Todo、图片、文件按钮可直接拖到画布定位；图片和文件松手后选择上传内容。拖到画布外或按 Esc 取消。
- 卡片拖动结束后按完整边界自动归组：完全位于分组框内则加入，否则移出；重叠时优先最小的完整包含分组框。空分组框保留。
- 点击分组标题栏不选中组内元素，拖动标题栏会移动所有层级的子分组及其卡片。子分组拖动、缩放后会按完整包含关系自动加入或离开父分组；重叠时选择最小父框，同尺寸分组不会互相嵌套。
- 分组标题栏右侧「自适应」按钮按当前所有成员（包括隐藏卡片、子分组边框）收紧或扩大边框，不移动内容。没有成员时保持原尺寸。

- 添加仅含内容的文字笔记、批量上传图片和任意文件，或直接拖入文件。
- 在画布中按 Cmd/Ctrl + V 粘贴剪贴板中的图片（包括截图）和文件，支持批量粘贴。可粘贴的文件类型取决于操作系统和浏览器是否向网页提供文件数据；输入框和编辑弹窗中保留原生粘贴行为。
- 拖动卡片定位；空白处拖动框选；Shift + 点击多选。
- 按住空格或 Ctrl/⌘ + 鼠标左键拖动画布，或使用移动工具；滚轮平移，Ctrl/⌘ + 滚轮缩放。
- 双击笔记直接编辑内容，无需标题；双击附件查看原图、Markdown、PDF、音视频，其他文件提供原文件下载。
- Todo 卡片可创建多项任务、勾选完成，双击编辑任务列表，状态随画布自动保存并支持导入导出。
- 分组框在创建时固定，移动内部卡片不会自动改变边框。拖动边或四角可调整尺寸，最小尺寸为 160 × 120 画布单位。
- 多选后创建并命名分组；按住画布中的分组标题栏可拖动整个分组（包括筛选隐藏的成员），双击标题栏在画布内原地重命名。侧栏支持按类型和分组筛选、重命名/解散分组。
- 自动保存到 IndexedDB，包括原始附件；导出 JSON 包含所有卡片、附件和分组，可重新导入。导入需要确认并替换当前画布。

## 数据说明

数据仅存于当前浏览器、当前网站来源下，不自动同步或上传。清理网站数据、更换设备、隐私模式或浏览器存储回收均可能丢失数据，请定期导出备份。附件与导出受设备内存和浏览器存储配额限制；保存失败时界面会提示。任意上传文件均作为附件处理，不执行 HTML 或脚本。请仅导入信任的备份文件；PDF 等原生预览取决于浏览器支持。

技术栈：React、TypeScript、Vite、Lucide；端到端测试使用 Playwright。

## 画布编辑

点击分组标题选中分组，不会选中内部卡片。Cmd/Ctrl + C 复制，Cmd/Ctrl + V 在当前画布中生成偏移的新副本；分组包含所有层级的子分组、卡片、任务状态和原始附件。副本使用独立 ID，保留内部层级。画布内部复制缓冲保留到刷新前，复制其他应用的内容后不会误粘贴旧副本。

Cmd/Ctrl + Z 撤销；Cmd/Ctrl + Shift + Z 或 Ctrl + Y 重做。拖动、调整边框的一整个手势为一次历史记录，编辑、创建、删除、导入和解散分组也可撤销。历史仅保留本次页面会话的最近 100 步；编辑框内保留浏览器原生撤销。

非分组卡片右键可将当前选择创建为分组（支持单个卡片）；分组标题右键可解散分组并保留内容。双击分组标题原地改名，Enter 或失焦保存，Esc 取消。

## 系统剪贴板复制

选中卡片后按 Cmd/Ctrl + C，成功后显示「已复制」。文字笔记可多选合并为纯文本；Todo 复制为任务清单；文本附件复制文件正文。图片复制为 PNG，可粘贴到支持图片的本地应用或编辑器。非 PNG 图片会转换为 PNG，动图仅复制静态画面；图片需逐张复制。

网页无法把任意附件写入 Finder/资源管理器的系统文件剪贴板。二进制附件可复制为画布内副本，向系统剪贴板仅写入文件名；同时提供「下载原文件」按钮；下载保留文件名和原始字节。不把文件链接或 Base64 当作原文件复制。文本附件在编辑器中粘贴为正文，不能在文件管理器里粘贴成原文件。

剪贴板功能需要 HTTPS（或 localhost）及浏览器授权；权限被拒绝会提示失败。编辑框内使用原生复制，不会复制画布选中卡片。

## 快捷键

输入框内保留系统快捷键；弹窗中可用 Esc 关闭，笔记和分组表单可用 Cmd/Ctrl + Enter 保存。

| 快捷键                     | 操作                                   |
| -------------------------- | -------------------------------------- |
| V / H                      | 选择 / 平移工具                        |
| 空格 / Ctrl / ⌘ + 左键拖动 | 临时平移                               |
| N / I / U                  | 新建笔记 / 上传图片 / 上传文件         |
| T                          | 新建 Todo                              |
| Cmd/Ctrl + C               | 复制选中卡片或分组（同时提供系统格式） |
| Cmd/Ctrl + V               | 粘贴图片与文件                         |
| Cmd/Ctrl + K               | 搜索                                   |
| Cmd/Ctrl + A               | 选择当前可见内容                       |
| Cmd/Ctrl + D               | 直接生成选中卡片或分组副本             |
| Cmd/Ctrl + G               | 创建分组                               |
| Cmd/Ctrl + Shift + G       | 移出分组                               |
| 方向键 / Shift + 方向键    | 移动选中卡片 1 / 10 个画布单位         |
| Enter / 双击               | 打开选中卡片 / 卡片详情                |
| Delete / Backspace         | 删除选中内容                           |
| + / -                      | 放大 / 缩小                            |
| 0 / 1                      | 适应当前内容 / 100% 缩放               |
| Cmd/Ctrl + O               | 导入画布                               |
| Cmd/Ctrl + Shift + E       | 导出画布                               |
| Esc                        | 关闭弹窗、取消选择                     |

Markdown 文件（`.md`、`.markdown`、`.mdown` 或 `text/markdown`）双击后渲染标题、列表、表格、任务列表和代码块。原始 HTML 不执行；其他附件仍可在详情中下载。

撤销/重做快捷键：`Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z`（或 `Ctrl + Y`）。
