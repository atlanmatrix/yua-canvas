# Canvas of Yua

默认将工作区保存在浏览器本地的无限画布，支持文本、工具、图片、代码文件、Markdown、PDF、Mermaid、Agent 对话、嵌套画布与本地应用关联。界面支持中文、English 和浅色、深色、跟随系统外观，语言与外观通过胶囊滑块切换；按钮和浮动工具栏使用无描边的胶囊外观，菜单和缩略图使用圆角矩形。普通控件使用半透明磨砂背景，设置和对话弹窗使用不透明背景，保留原有圆角形状；阴影由外层浮动容器承担，菜单项、工具栏图标、表单及节点内部控件保持平面，通过背景色、选中状态和键盘焦点提示反馈；分享页和 3D 预览遵循相同规则。无需账号即可使用；可选云同步、登录和只读分享的部署说明见 [worker/README.md](worker/README.md)。

界面图标采用 SVG 部件动画：悬浮约 440ms、按压约 160ms、点击约 640ms，动作幅度加大，悬浮转点击和移出时从当前姿态平滑衔接，图标外部控件保持原有尺寸、形状和阴影。鼠标、键盘和触屏共用反馈；加载动画跟随实际请求状态。画布移动时暂停装饰动画，系统开启「减少动态效果」时停止运动，PNG 导出始终使用静态图标。图标统一从 `src/icons.tsx` 引用，自定义 SVG 通过 `animatedIcon` 接入，部件动画集中在 `src/iconMotionRecipes.ts` 维护。

画布内的触摸板四向滑动会拦截浏览器的前进、后退、下拉刷新和页面回弹。组件内可滚动的内容优先使用原生滚动，到达边界后不会带动画布或触发浏览器手势；浏览器按钮和快捷键仍可正常导航。

## DeepSeek Harness 插件

Canvas 可作为 DeepSeek Harness（dsh）的 Web UI 插件安装，在左侧导航中打开。完整安装和数据迁移说明见 [dsh/README.md](dsh/README.md)。

```sh
npm run build:dsh
dsh plugin --profile web add /absolute/path/to/yua-canvas/dsh
dsh web
```

`npm run pack:dsh` 生成可安装的 `dist/dsh-yua-canvas-1.0.0.tgz`。插件保留本地 IndexedDB 与 JSON/ZIP 备份；原网站数据需导出后导入。`npm run test:dsh` 验证插件打包、路由、导航及嵌入画布。

## 画布操作

- 双击空白处创建文本；画布右键「新建」可创建文本、图片、文件、Mermaid、Agent、Miniature 或分组，位置按右击点计算。「新建工具」包括 TODO、计算器、汇率计算、摄氏度 / 华氏度、距离单位转换、天气和日历。新建文件直接生成可编辑的文件组件；已有文件可上传、拖入或粘贴。
- Agent：画布右键「新建 → Agent」，点「配置 Agent」填写 API Key、模型和接口地址。默认使用 OpenAI Responses；兼容服务可切换 Chat Completions，接口地址填写 API 根路径（例如 `https://api.openai.com/v1`），服务需允许浏览器跨域请求。支持系统提示词、多轮流式对话、停止、重试与新建对话；Enter 发送，Shift + Enter 换行。Key 按节点和接口地址单独保存在当前浏览器，清空后保存可移除，不进入 JSON / ZIP、云同步或分享；对话记录会随画布保存。恢复到其他浏览器或复制节点后需重新填写 Key。只读分享和 3D 预览仅显示对话，不发起模型请求。
- 除分组和子画布外，组件右键提供小、中、大三档显示模式，默认新建为中尺寸，Agent 默认使用大尺寸以便直接对话。小尺寸显示类型图标，中、大尺寸按内容比例展示，中尺寸保持统一缩放，避免宽高独立裁切造成空白；文本编辑和展示使用相同缩放，普通与 Retina 屏幕下均不会在结束编辑时突然缩小。PDF 大尺寸宽高为中尺寸的 150%，页面和图表会按实际内容比例调整。切换模式保留原始内容与布局数据。
- 所有组件和分组支持遮罩、右侧备注及背景色。遮罩会卸载实际内容。分组支持平铺或列表：列表左侧选择组件，右侧显示内容，切回平铺保留原坐标。
- 文本双击后在画布内编辑，浮动工具栏支持字体、字号、加粗、倾斜、下划线、删除线、文字颜色和背景色。Cmd/Ctrl + Enter 完成，Esc 取消整次修改。
- TODO 双击事项会从点击位置继续编辑，双击标题或空白处新增事项；Enter 在当前项后新增。原有事项 ID、完成状态与连线保留，整次编辑可撤销。
- 粘贴图片按原始像素尺寸展示；宽度超过 2560 或高度超过 1440 时，默认按 50% 展示。原始文件字节保留。普通文件上传仍使用适合画布的初始预览容器。
- 画笔入口位于底部工具栏左侧，间隔 12px。点击或按 P 进入绘画模式，顶部工具栏提供颜色、粗细、撤销、清空、隐藏和退出；Esc 退出。笔迹自动平滑，位于组件内容上方，隐藏状态和笔迹随画布保存。
- 触屏支持单指拖动空白处平移、拖动节点移动、双指平移和以双指中心捏合缩放；双击空白处新建文本，双击节点编辑，长按空白处、节点或分组打开菜单。Agent 对话和设置、可滚动预览支持单指滚动；输入框保留键盘和文本编辑行为。选中组件后，触屏模式显示四角 1/4 圆弧缩放手柄，点击范围随画布缩放保持屏幕尺寸；可拖动调整大小，取消手势会恢复调整前尺寸。触屏连接点常显并扩大点击范围，捏合会结束当前拖动或取消未完成的画笔笔迹。
- 普通拖动移动组件，空白处拖动框选。Shift 或 Cmd/Ctrl + 点击增减多选；右键拖动、空格拖动或 Cmd/Ctrl + 拖动平移。滚轮平移，Cmd/Ctrl + 滚轮缩放。鼠标拖动组件或分组缩放手柄时按住 Shift，按原始宽高比调整并固定对侧锚点；图片、PDF 和图表始终保持内容比例。
- 悬浮组件后，可从边缘的「+」拖出带箭头的曲线连线；TODO 每项有独立连接点。双击曲线或标签编辑连线文字，Enter / 失焦保存，Esc 取消。删除组件或事项会清理相关连线。
- 分组标题可拖动全部后代成员，双击重命名。成员部分越界时分组扩张，完全离开时保留原边框；分组可独立调整尺寸、解散或删除。
- 左下角缩略图显示组件、分组、连线和笔迹，蓝框表示视口，可拖动定位。灰色画布边框对应缩略图完整范围。不提供侧栏、搜索或筛选。
- 组件或分组可设置 Pin；点击后以非线性平移及先缩小后放大的动画定位，额外缩小最多 10%。目标超出视口时用 1600ms，视口内按距离用 400–1000ms。拖动、滚轮、Esc 或再次定位可以打断动画。

## 文档、图表与应用关联

- 粘贴文本会检测 JSON、Markdown、Python、JS/TS、CSS、Shell、SQL、YAML/TOML、HTML/XML、Go、Rust 等结构，生成带扩展名的可编辑文件。单个带语言标记的代码围栏按标记创建文件并去除围栏；不明确的普通文字保持文本组件。Mermaid 延续直接生成图表的行为，可下载 `.mmd` 源码。
- 上传、粘贴的源码文件及 Markdown 围栏代码块支持 highlight.js 的 193 种语言，并增加 CSV 高亮。代码只作为文字显示，HTML、脚本及 Shell 均不会执行。染色在独立 Worker 中串行处理，并有容量上限的缓存；预览最多 64 KB，编辑和下载保留完整文件。显式围栏支持的语言比无标记自动检测更广，无法可靠判断时可通过编辑文件名指定格式。
- Markdown 文件直接渲染标题、列表、表格、代码块及任务列表。双击打开详情，可编辑完整内容、文件名，预览未保存的修改；保存保留编码、BOM 和换行惯例。原始 HTML 不执行。
- PDF 直接预览，默认首页；悬浮、选中或触屏时显示分页栏，支持上下页、输入页码跳转和缩略图侧栏，长文档仅渲染可见缩略图。画布缩放或组件尺寸变化后按屏幕像素密度重新渲染，Retina 屏幕下保持清晰。当前页码随本地保存、同步和备份保留，只读分享中的翻页仅临时生效。字体、CMap、解码器与 Worker 随应用构建，支持离线和部署子路径。
- 粘贴 Mermaid 代码或单个 Mermaid 围栏块会生成独立图表，也可从右键菜单创建。画布只显示完整图表，双击弹窗编辑。Markdown 中同时支持 Mermaid 和传统 flowchart.js 围栏语法；解析失败时保留可编辑源码。
- 画布右键「新建应用关联」可添加 VS Code 或 iTerm2。VS Code 胶囊带图标，使用官方协议的 `windowId=_blank` 参数在新窗口打开配置的完整本地路径。
- iTerm2 组件支持多行命令，每行前显示 `>` 图标，悬浮时可复制或执行，双击配置。首次执行按弹窗安装 macOS 本地打开器，之后每次在 iTerm2 新窗口输入命令。配对密钥仅保存在当前浏览器及用户安装的打开器中，不进入工作区备份或云同步。只读分享不会执行应用关联；macOS 应用启动及自动化权限仍需实机验证。
- 底部工具栏可创建子画布，顶部返回父画布；根画布还可从右键创建一次父画布。每层的内容、平移、缩放和上次所在层级分别保存。
- 缩略图右键「3D 预览」打开 `#/3d` 分层视图。支持拖动旋转、滚轮缩放、Shift / 右键平移和触屏手势；双击组件返回其画布并打开。3D 预览不改变组件布局。
- Miniature 可配置 HTTP / HTTPS 场景 URL 或 iframe 代码，只提取地址与标题。双击激活交互，点击外部保存视角和静态封面并释放 iframe。自动封面依赖场景实现 `little-worlds:ready/statechange/capture/response` 协议；仅允许来源窗口、源站和请求标识匹配的响应。未实现截图协议的场景仍可手动交互。

## 工具、语言与外观

- 工具直接在画布内交互，拖动标题移动；输入不会触发画布快捷键。与其他组件一样支持三档显示模式、遮罩、备注、分组、复制、撤销、JSON / ZIP 备份与云同步。工具状态保存在组件数据中，网络响应作为可丢弃的本机缓存保存。
- 计算器支持括号、小数、百分比、乘方、常量 `pi` / `e` 与 `sqrt`、`abs`、`sin`、`cos`、`tan`、`log`、`ln`（三角函数使用弧度），表达式通过独立解析器计算。保存当前表达式及最近历史。距离支持 mm、cm、m、km、in、ft、yd、mi 和 nmi；温度支持摄氏度与华氏度，单位均可交换。
- 汇率通过 Frankfurter / ECB 获取，显示实际汇率日期（交易日数据），支持常见币种，缓存一小时。天气通过 Open-Meteo 搜索城市，展示当前温度、体感、湿度、风速和三日预报，缓存半小时；默认北京，选择的城市会记住。刷新失败时有缓存则展示并标明可能过期，无缓存则显示请求失败，不生成虚构数据。这两项在线数据需要能访问相应的公共服务；计算器、单位转换与日历可完全离线使用。
- 日历支持切换月份、选择日期、返回今天，所选月份和日期随组件保存。只读分享中的工具允许临时计算或切换，不修改发布的快照。
- 右上角齿轮打开设置菜单，语言、外观保持滑块切换，两组控件采用浅色扁平轨道与滑块；云同步与分享、导入、导出及可用的更新操作逐行排列。菜单中显示保存与离线状态，点击外部或 Esc 收起。设置保存在当前浏览器并在分享页生效。语言切换只改变界面，保留用户的笔记、任务、文件和自定义名称；外观变化不改写工作区颜色数据。系统外观变化会实时生效。左上角子画布名称与返回入口使用白底胶囊。

## 大画布预览性能

卡片的布局、连接点和选择范围始终保留；附件和图表内容由共享可见性观察器按需激活，在视口周围预留 320px。离开范围后延迟释放，正在聚焦或选择文字的内容保持活跃。平移、缩放过程中暂停启动新的重预览，停下约 160ms 后补充内容。缩得很小的文档先显示轻量类型图标，悬浮或放大后恢复预览，保存的显示模式不变。

卡片通过独立的 memo 组件与稳定事件桥隔离相机更新；缩略图卡片和投影也避免无关计算。位置、显示模式、编辑和选中状态改变时仍正常更新对应组件。

- PDF 解码及页面渲染最多 2 个并发任务，取消离屏队列任务，复用短期文档实例。文档池限制数量及附件字节，并在空闲约 10 秒后释放；正在使用的文档不会被淘汰。
- 页面预览按文件内容、页码和清晰度分档缓存，根据屏幕像素密度及显示面积选择清晰度，最长边上限 8192 像素、单页最多 12M 像素，使用无损页面位图。内存 LRU 按估算像素成本限制为 64MB；独立的 IndexedDB 派生缓存最多 128 项、64MB，刷新后可复用。缓存不可用或写入失败时仍可正常预览和保存原文件。
- 文本解码结果和 Markdown 解析树分别有容量上限；超过 64 个顶层块的 Markdown 按块组虚拟化显示，滚动到相应位置再挂载内容，保持完整文件及文内引用。
- Mermaid / flowchart.js 串行渲染并复用已清理的 SVG，实例使用独立 ID，避免重复图表的箭头、裁剪和样式相互干扰。

这些缓存都可重新生成，不属于工作区数据，不进入导出或云同步；淘汰缓存不会删除原始附件。性能回归覆盖离屏加载数量、相机移动时的卡片更新、渲染并发、缓存失效、翻页恢复及长文档滚动，具体帧率仍取决于设备和文档复杂度。

## 保存、备份与云服务

本地数据位于当前浏览器、当前网站来源的 IndexedDB。最后一次操作后约 0.6 秒自动保存，视口变化不计入内容撤销历史。更换网站来源或浏览器不会自动迁移数据，请定期导出。

顶部「导出画布」始终导出整个工作区，包括父级、兄弟、子画布、原始附件、分组、任务、连线、Pin、样式、备注、笔迹、隐藏状态与各层视图。导出使用当前内存状态，无需等待自动保存。完整备份导入会确认替换范围，事务写入成功后应用，并可撤销；旧版单层画布 JSON 仍可导入当前层。

多选组件或分组后右键「导出」，可选画布 JSON、组件压缩包和 PNG 图像，自动包含所选组件之间的连线。ZIP 保留原始字节和布局元数据。设置中的同名导出菜单以 JSON / ZIP 备份整个工作区，PNG 导出当前画布；PNG 按内容范围裁边，保留屏蔽状态，不包含选择框或画布操作控件；默认以 2 倍像素导出，超大画布会自动降低比例，最长边不超过 8192 像素、总像素不超过 16 MP。上传、拖入或粘贴带元数据的 ZIP 会以独立 ID 合并；普通 ZIP 展开为附件。损坏或缺少引用文件时不会部分导入。剪切缓存可跨刷新恢复，但系统剪贴板必须保留对应标识。

可选云服务按账号同步完整工作区，支持固定快照分享、有效期和撤销，配置见 [worker/README.md](worker/README.md)。分享令牌允许持有者读取和下载；撤销不能收回已下载的数据。浏览器存储回收、清理网站数据或卸载应用可能丢失本地工作区，派生预览缓存不能代替备份。

## 部署、安装与离线

推送 `main` 后，[GitHub Pages 工作流](.github/workflows/deploy-pages.yml) 自动构建部署；仓库 Pages 来源应设置为 GitHub Actions。项目默认地址为 <https://atlanmatrix.github.io/yua-canvas/>，实际结果以 Actions 为准。

```sh
npm run build -- --base /yua-canvas/
npm run preview -- --base /yua-canvas/ --port 4173 --strictPort
```

`dist/` 也可部署到其他静态托管服务。云服务使用同域 Worker 站点；GitHub Pages 入口使用本地模式。

推送任意 tag 后，[Release 工作流](.github/workflows/release.yml) 自动从该 tag 构建并发布 GitHub Release，附带以下文件：

- `yua-canvas-deploy.zip`：已构建的静态站点，包含 PWA、PDF 字体、解码器和 Worker 等资源。解压后的 `index.html` 位于包根目录，将全部内容放入静态托管目录即可；资源使用相对路径，支持根目录或子目录部署，通过 HTTP(S) 访问。
- `yua-canvas-source.zip`：该 tag 对应的完整已跟踪源码，包含锁文件、构建脚本和可选 Cloudflare 后端配置；云端数据库、存储和登录的配置见 [worker/README.md](worker/README.md)。
- `dsh-yua-canvas-*.tgz`：可安装的 DeepSeek Harness Web 插件，包含画布及 PDF、图表等资源，安装方法见 [dsh/README.md](dsh/README.md)。
- `SHA256SUMS`：以上安装包的 SHA-256 校验值。

例如 `git tag v1.0.1` 后执行 `git push origin v1.0.1`。工作流使用内置 `GITHUB_TOKEN`；同一 tag 的工作流重新运行时更新附件并保留已有 Release 描述。打包成功后才会创建 Release，已有的 Pages 部署流程保持原有触发方式。

本地可验证 Release 使用的相对路径构建：

```sh
PWA_BUILD_BASE=./ npm run test:pwa                  # 部署在 /yua-canvas/ 下
PWA_BUILD_BASE=./ PWA_TEST_BASE=/ npm run test:pwa  # 部署在站点根目录
```

生产版支持 PWA 安装。首次联网加载后，应用外壳和构建资源可离线使用；API、会话和云端附件不进入 Service Worker 缓存。登录、同步和打开尚未加载的分享仍需网络。

发现更新时显示「更新应用」，点击后先保存工作区再重新加载，其他标签页不强制刷新。Manifest、Service Worker 和 PDF 资源跟随部署子路径。图标源文件为 `public/icon.svg`，修改后可执行 `npm run icons` 重新生成安装图标。

## 多服务器同步

设置中的「云同步与分享」默认包含 Yua Cloud（`https://yua-worker.atlanmatrix.workers.dev`），并保留当前站点和已保存的服务器。点击服务器名称打开管理弹窗；右侧开关独立控制自动同步，可多选或全部关闭。底部浅灰分隔线下为「新增服务器」：填写地址、名称并确认后，收起表单并测试连接，黄色圆点表示正在连接，绿色表示成功，连续三次失败后显示红色；Github 右侧的刷新图标可重新检测。登录与手动拉取、上传均不会自动开启同步。拉取前保留本地恢复副本，上传使用云端当前版本检查并在替换已有内容前确认；退出账号需再次确认。名称、地址和开关状态保存在当前浏览器，各服务器的登录和版本基线相互独立。关闭开关会停止后续自动同步并取消尚在进行的网络请求；已经被服务器接受的写入不会撤回。

云同步使用 `src/cloud.css` 中的独立配色变量，避免画布内容或玻璃透明效果降低控件可读性：

| 场景 | 浅色主题 | 深色主题 | 搭配规则 |
| --- | --- | --- | --- |
| 弹窗与正文 | 浅灰 `#f3f4f6` / 黑 `#171717` | 深灰 `#202124` / 白 `#ffffff` | 使用不透明背景 |
| 输入框、普通按钮 | 白底 / 无常驻描边 | 灰底 `#35383c` / 无常驻描边 | 使用填充色区分控件，聚焦时显示蓝色外框 |
| Github、主要操作 | 黑底 `#111111` / 白字 | 黑底 / 白字 | 悬停使用深灰，不使用浅字配浅底 |
| 选中、悬停、焦点 | 浅蓝底 `#e2efff` / 深蓝灰字 | 蓝灰底 `#294461` / 白字 | 焦点另加蓝色外框 |
| 禁用控件 | 浅灰底 / 深灰字 | 深灰底 / 浅灰字 | 不用整体透明度稀释对比度 |
| 连接状态 | 红、绿、黄圆点 | 对应较亮色圆点 | 颜色仅表示状态，附可访问名称和悬停提示 |

输入框与按钮采用约 32–34px 的紧凑高度，滑块轨道为 30×18px；普通控件与下拉选项不使用深色描边。

分享有效期使用应用自绘下拉框，支持键盘、触屏和屏幕阅读器，不依赖浏览器原生 `select` 外观。

服务器地址应为 HTTPS 来源，不包含 `/api`、子路径、查询或用户信息；本地开发可用 localhost HTTP。现有同源云服务显示为「当前站点」。新独立后端见 [yua-worker](https://github.com/atlanmatrix/yua-worker)，运行于 Cloudflare Workers，使用 Supabase PostgreSQL 与私有 Storage。需先在后端配置此 Canvas 的来源以及 GitHub OAuth，再在 Canvas 添加 Worker 地址。Supabase service_role key 不得放入前端。

多个服务器同步同一个本地工作区，不自动合并不同远端内容。各服务独立比较版本；有冲突时暂停该服务器，用户可备份后采用远端或以本地发布新版本。分享链接包含服务器来源，接收者无需预先添加该服务器；附件始终从分享所属服务器读取。未选择服务器时保留 IndexedDB 本地模式。
